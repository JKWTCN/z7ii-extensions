# ZRV 转 CinemaDNG

Windows x64 图形工具，用于导出尼康 Z7 II C 1.70 RAW 直录模块生成的 `.ZRV`。

1. 打开 `ZRV-CinemaDNG.exe`，选择或拖入 `.ZRV` 首段。工具会自动读取同目录下同名的 `.Z00`、`.Z01` 等续段。拖入单独的续段则只处理该段。
2. 保留默认输出位置，或点 **选择位置**。普通导出创建 `片段名_CinemaDNG`，同步导出创建 `片段名_CinemaDNG_MOV`。
3. 点 **开始转换**。完成后点 **打开输出目录**，将里面的编号 DNG 文件按窗口显示的帧率导入。

v1.27 支持带 `ZMS1` 对应表的 ZRV13。打开 `.ZRV` 首段后，选取同期同名 MOV 或 MP4 并勾选 **同步到 MOV**。若视频和 RAW 位于同一目录，会自动找到同名文件。输出至 `片段名_CinemaDNG_MOV`，按原厂视频轨的帧数与帧号排列，缺少 RAW 画面的区间补黑，丢帧表也使用 MOV 的时间线。有 PCM 时同步后的 WAV 在缺少录音的位置补静音。关闭麦克风录制的片段也可按机身写入的映射同步。

v1.27.3 支持 2070×1166 RAW12 ZRV13，包括 FX 1080p50／59.94 同步录像。可合并续段并按 MOV 时间线导出 DNG 和 PCM。

v1.27.11 读取 ZRV 的机身方向标记并写入每帧 DNG 的 TIFF Orientation，支持横拍、两个竖拍方向及倒置。旧文件使用原有横向方向。

v1.27.10 支持带 H.264 显示顺序表的原厂 MOV。转换器验证整个视频轨的显示时间点都处于连续的固定帧率时间线上，然后按原厂视频轨的帧数同步输出。

v1.27.9 可读取 2070×1166 RAW12 ZRV12。1080p 单录或关闭 MOV 同步时也可按源片帧号补齐超时帧并导出 CSV。

v1.27.8 修复「超时帧补齐」标签挡住下拉框的问题。同步导出生成三个独立 CSV，分别为总表、`*_timeout.csv` 和 `*_sync.csv`。无法确定来源的空位只在总表中标为「类型待确认」。

v1.27.7 手动导出帧表时选择保存文件夹，转换器按片段名生成 CSV。遇到同名文件时自动加 `_2`、`_3` 等编号。

v1.27.6 同步到 MOV 时也可选择「超时帧补齐」。选择「复制前一帧」会用最近一张实拍 RAW 补齐已找到 MOV 帧号的超时帧。同步帧和首张实拍前的超时帧补黑。

v1.27.4 在 MOV 同步预览中分别统计「超时帧」和「同步帧」。超时帧是 ZRV 标记为丢帧且落在 MOV 时间线中的帧。同步帧是为对齐 MOV 补上的黑帧。源片信息继续显示整条 ZRV 的超时帧总数。

v1.27.1 利用区间两侧的机内帧号补全缺失的同步编号。只有区间内的 MOV 空位与 RAW 帧数相等时才补全，可跨 `.Z00` 等续段。同期 MOV 结束之后的 RAW 保留在素材中，可用普通导出取得。

v1.27.2 会分别显示源 ZRV 时长和当前导出时长。同目录的同名 MOV 或 MP4 验证通过后，默认勾选 **同步到 MOV**。取消勾选可按源片时长导出。

v1.26 支持 FX 1080p50／59.94 的 2070×1166 RAW12 ZRV10。DNG 保留 `50/1` 或 `60000/1001` 帧率，首段及续段可合并导出连续的 48 kHz 双声道 WAV。59.94p 的续段也能按本段记录的音频相位独立导出。

v1.25.1 会显示 ZRV12 的丢帧数。丢帧数为 0 时也可以手动导出丢帧表，CSV 只有表头。旧格式的状态栏会显示「无丢帧明细」。

v1.25 自动使用最多四个工作线程解码和写入 DNG。导出按原帧号命名，使用「复制前一帧」时，同一张实拍画面只解码一次。

v1.24 合并导出首段和续段，生成一套连续编号的 DNG 和一个 WAV。工具会核对续段编号、源帧号和 PCM 相位。跨段缺帧使用上一段最后一张有效画面补齐，适用于「复制前一帧」模式。

「导出丢帧表」可单独输出 CSV。转换含丢帧标记的录像也会在 DNG 序列目录中自动生成 `*_dropped_frames.csv`。表中列出所在分段、源帧号、本段帧号、合并后的 DNG 帧号与序列内时间。

v1.23 支持 ZRV12 的丢帧标记。转换器采用机内保存的补帧选项，也可以在「丢帧补齐」中改选「插入黑帧」或「复制前一帧」。独立打开的分段如果从缺帧开始，复制前一帧模式会用黑帧补到本段第一张实拍画面。WAV 保留原录音。

v1.22 支持 3826×2158 的 ZRV11。同一段可以逐帧使用原厂 NEF 无损压缩或打包 RAW12。首段和续段均可按源帧顺序导出 CinemaDNG 及对应的立体声 WAV。

v1.21 支持 PCM v20 写入的 3826×2158 未压缩 RAW12 ZRV10，包括 29.97p 独立续段和立体声 WAV。

v1.20 支持 PCM v14 的 4K 无损 RAW 和 1080p 档原尺寸 RAW12，在 23.976p、25p、29.97p 下按文件头的分数帧率导出 DNG。每一段独立导出 WAV，29.97p 续段从原片段的音频采样位置接续。

v1.19 将机身录制状态和电脑导出结果分别显示。ZRV9 文件尾记录源缓冲过期时，界面标出中断的源帧号；此前已经写入文件的完整帧仍可转换。

v1.18 起可选择或拖入同一条录像的 `.ZRV` 首段及 `.Z00`、`.Z01` 等续段。逐段导出时，续段的输出目录、DNG 序列及 WAV 文件名均保留分段扩展名，例如 `Z72NM000.Z00_CinemaDNG`。

v1.17 支持 PCM v10 录制模块产生的 ZRV9 单文件及按大小分段文件。每个文件可独立转换。音频从文件中的各个 PCM 块按时间顺序导出，缺失区间补静音。音轨超过标准 WAV 的长度限制时使用 RF64。

v1.16 起会把 ZRV 内的 48 kHz、16 位双声道 PCM 导出为同目录、同片段名的 WAV。在时间线上将 WAV 与第一张 DNG 对齐。若机身只取得部分声音，窗口显示「部分 PCM」；首个有效采样晚于画面的已知间隔在 WAV 开头补零。没有取得采样时仅导出画面。

支持 `ZRS1` 的 25 fps RAW12 录像，以及每隔两帧、三帧或八帧保存的 2070×1166 RAW12 文件。文件尾缺失时，窗口会提示并导出此前完整、符合采样间隔的帧。转换期间可以取消，同名的已有输出目录会保留。

v1.5 支持两代全尺寸无损实验版的 `Z72RLnnn.ZRV`。解码后导出的 DNG 保留原始 RAW12 采样和 12.5 fps。

v1.6 增加对 FX 4K25 实验模块的 3826×2158 RAW12 帧的读取和导出，每行步长为 5744 字节。

v1.7 支持原厂 NEF 硬件无损压缩实验版的 `Z72NZnnn.ZRV` 和 `Z72NMnnn.ZRV`，以 3826×2158、12.5 fps 导出。

v1.8 同时支持采用 DMA 转存、帧尾对齐到 64 字节的原厂无损 ZRV。

v1.9 支持 750 帧上限的 4K 无损 ZRV，可读超过 4 GiB 的单段录像。

v1.10 支持 4K 直录中超过 7 MiB 的原厂 NEF 无损帧。

v1.11 支持 3826×2158 无损 RAW12 的 250 帧上限，按 25 fps 导出 v55 的完整片段或已保存的连续帧。

v1.12 支持 v56 的 30 秒无损 RAW12 片段，按 25 fps 读取最多 750 帧，包括跨越 4 GiB 单文件边界的帧。

v1.13 支持 v59 记录的 UHD `30000/1001` fps。导出的 CinemaDNG 使用精确的有理数帧率，并从零起按 30 帧非丢帧时间码编号。

v1.14 增加 UHD `24000/1001` fps 支持。导出时保留该分数帧率，从零起按 24 帧非丢帧时间码编号。

v1.15 支持 v67 从 FX 4K 50p 录像中的相邻 RAW 槽采集的 3856×2176 双帧 ZRV，按源槽实际更新节奏标记为 25 fps；只有一帧成功保存的片段也可导出。

序列采用无压缩 CFA DNG，以 16 位字段原样保存 RGGB RAW12 采样值。每帧写入实际帧率和片段名。25 fps 序列另写从 `00:00:00:00` 开始的时间码。白电平为 4095。工具从 `.ZRV` 自动读取黑电平，旧片段以估计值 256 起步，均可在窗口中调整。色彩矩阵及日光白平衡沿用仓库里 Python 导出器的初始值。

## 构建

```powershell
cargo rustc --release --locked --manifest-path tools/zrv_cinemadng/Cargo.toml --target-dir tools/zrv_cinemadng/target/portable -- -C target-feature=+crt-static
```

生成 `tools/zrv_cinemadng/target/portable/release/zrv-cinemadng.exe`。
