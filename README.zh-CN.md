# Z7II Extensions

[English](README.md) | 简体中文

Nikon Z 7II C 1.70 的 SD 卡原生 C 扩展框架，开机自动加载卡上的模块。

## 当前功能

| 功能                            | 说明                                     | 状态                     |
| ------------------------------- | ---------------------------------------- | ------------------------ |
| [取景网格](docs/framing-grid.md) | 关闭、4×4、3×3、黄金分割，支持保存设置 | 已实机验证，包含重启恢复 |

## 使用

需要先安装配套 SD 加载宿主；原版固件不能直接加载模块。已安装宿主的相机无需重新刷固件。

1. 等待存储卡访问结束，关机并取出电池约 30 秒。
2. 将 [Z72APP.BIN](releases/v0.1.0-preview.1/Z72APP.BIN) 放到 SD 卡根目录，已有 `Z72APP.CFG` 可保留。
3. 装回卡和电池，开机。

当前版本：`v0.1.0-preview.1`，模块 3,168 字节。[SHA-256 校验](releases/v0.1.0-preview.1/SHA256SUMS)

这是试用版本，休眠唤醒和长期稳定性尚未单独确认。替换或移除模块请完整断电。只加载可信模块。

## 构建

需要 Python 3.12，以及 PATH 中的 LLVM `clang`、`ld.lld`。使用 `tools/module.py` 构建插件，具体命令见对应功能文档。输出文件必须不存在。

`host/` 为宿主源码，`sdk/` 为模块接口，`plugins/` 为插件实现。

`tools/build.py` 生成完整固件升级包及 JSON 校验报告。需要精确匹配的原版 C 1.70 升级包，以及 LLVM `llvm-objcopy`、`llvm-nm`：

```powershell
New-Item -ItemType Directory -Force artifacts | Out-Null
python -B tools/build.py --stock-package "path/to/original/Z7_2_0170.bin" --output artifacts/Z7_2_0170.bin
```

脚本内部自动提取主固件，无需另行解包、提供主固件文件或私有打包材料。脚本复用已验证发布包的公开头部校验值，强制核对输入、编译后的宿主及完整输出的 SHA-256，并重新解包核对所有成员。固定校验值仅适用于当前发布版本，因此宿主构建发生变化时会拒绝输出。输出文件必须不存在。仓库不包含原版固件或生成的升级包。
